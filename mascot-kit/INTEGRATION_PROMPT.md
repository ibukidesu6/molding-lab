~/molding-lab（MOLD LAB）に、先生ネコのマスコットを「動く先生＋吹き出しコメント」として組み込んでほしい。

## 素材
- `mascot-kit/out/01.webm`（いいね！：両手を振る）
- `mascot-kit/out/02.webm`（ダメだよ！：真剣な顔）
- `mascot-kit/out/03.webm`（こうしてみよう！：指さし）
- `mascot-kit/out/05.webm`（やったー！：ジャンプ）
- 待機用の静止画：`mascot-kit/00_main_cutout.png`（透過PNG）
- ④うーん… と ⑥もう一回やってみよう！ は未生成。あとから `04.webm` / `06.webm` を置けば使われるようにして、それまでは代わりのクリップで動くようにする（④→03、⑥→01）。

各クリップは約5秒、720×720、VP9 alphaの透過WebM。最初と最後がほぼ同じ立ちポーズ。

## ゲームの中での役割
先生ネコは「横で見ていて、ひとこと言ってくれる先輩」。説明役ではない。
UI方針「全部見せない」を守る。常に喋っているのではなく、変化の瞬間だけ出てきて、すぐ引っ込む。

| タイミング | モーション | セリフ例（ja） |
|---|---|---|
| ミッション開始（setup表示時、初回のみ） | ①いいね | 「まずは そのまま 押してみよう！」 |
| 成形中 | 出さない（または小さく待機） | — |
| 結果：good | ⑤やったー | 「やったー！きれいに できたね！」 |
| 結果：不良（short / flash / sink） | ②ダメだよ → ③こうしてみよう | 「あっ、{不良名}だ！」→「{パラメータ}を{上げ/下げ}てみよう！」 |
| 同じ不良が2回続いた | ④うーん…（仮は03） | 「うーん…原因を 見てみよう」＋原因確認への導線 |
| 「もう一度」ボタンを押したとき | ⑥もう一回（仮は01） | 「もう一回 やってみよう！」 |

- 不良時のヒントは `simulate.ts` の `SimResult.hints`（`{ param, dir }`、最大2件）の先頭1件から作る。パラメータ名は i18n の既存ラベルを使う。
- 1回の結果につき吹き出しは最大2つまで。②が終わったら③に自然につなぐ。

## 実装の要件
1. **コンポーネント**：`src/components/Mascot.tsx`（動画＋吹き出し）と、状態からセリフとクリップを決める純粋関数 `src/game/coach.ts` に分ける（ロジックとUIの分離を守る）。
2. **動画**：`<video muted playsInline>` でクリップを1回再生し、終わったら静止画の待機状態に戻す。待機中はCSSでゆっくり呼吸するような上下の揺れを付ける。クリップは切り替えたときに一瞬消えないよう、事前に読み込んでおく。
3. **Safari対策**：Safari は VP9 alpha の透過が効かない。ffmpeg の `hevc_videotoolbox`（`-alpha_quality`）で HEVC alpha の `.mov` も作り、`<source>` を mov→webm の順に並べる。変換コマンドは `mascot-kit/process.sh` に追記する。
4. **吹き出し**：
   - ネコの頭の横から出る。しっぽ（三角）がネコの方を向く。
   - ぽよんと飛び出して出てきて、文字は1文字ずつ表示（口パクの間だけ）。
   - クリップが終わってから約1.5秒で消える。クリックかタップで早送り・閉じる。
   - 見た目はトイ調で統一する：紺のアウトライン、硬いドロップシャドウ、角丸。色は必ず `src/theme.ts` の palette／`--c-*` 変数から取り、直書きしない。絵文字は使わない。
   - 不良時は吹き出しのフチを error 色、good は success 色にする。
5. **配置とサイズ**：ステージ（金型）の左下隅に置き、金型と操作ボタンに重ならないようにする。幅の目安は 1200px で 160px、768px で 120px、390px で 88px。スマホでは吹き出しをネコの上に出す。
6. **i18n**：セリフはすべて `locales/ja.ts` の `coach` 以下に置き、`en.ts` も型チェックが通るように英訳を入れる。`{param}` `{defect}` などの差し込みに対応する。
7. **設定**：左ドロワーに「先生を表示」のON/OFFを追加し、progress（localStorage）に保存する。`prefers-reduced-motion` のときは動画を再生せず、静止画＋吹き出しだけにする。
8. **素材の配置**：使う webm/mov/png を `public/mascot/` にコピーする。ファイル名はモーション名にする（`cheer` `no` `idea` `think` `yay` `again`）。

## 確認
- `npm run build` が通ること。
- 390 / 768 / 1024 / 1200 × ja / en × 各状態（setup、成形中、good、short、flash、sink、2回連続の不良）を iframe で自動チェックし、吹き出しのはみ出し、金型との重なり、文字の切れがないことを確認する。
- Chrome と Safari の両方で、背景が透過していることを確認する。
